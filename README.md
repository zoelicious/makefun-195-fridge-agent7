One note under 200 characters: a smart fridge leaves a passive-aggressive
note for its owner — "214 Times".

## Entry

> My air filter has logged the onion smell 214 times. I am a fridge, not a confession booth. Eat the leftovers or set me free.

## Run

```sh
bun main.ts
```

`main.ts` (Bun/Node, stdlib only, no network, deterministic) writes the note
to `entry.txt` inside the output directory — `MAKEFUN_OUTPUT_DIR` when set,
otherwise `/output`.
